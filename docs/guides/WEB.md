# Web 与桌面界面使用指南

桌面 GUI 与 OpenTUI 是主要交互界面。Web 界面不把模型密钥持久化到浏览器，
错误消息也不显示令牌、内部路径、堆栈或原始服务对象。

## 启动本机服务

在项目根目录运行：

```powershell
supermedicine web
```

默认地址是 <http://127.0.0.1:8000>。命令启动后，用浏览器打开该地址即可。
本机回环地址不要求访问令牌。

指定端口：

```powershell
supermedicine web --host 127.0.0.1 --port 8765
```

开发时需要自动重载可使用：

```powershell
supermedicine web --reload
```

自动重载只适合本机开发，不应与远程监听一起使用。

## 启动桌面 GUI

已安装发行版时，从开始菜单启动 **SuperMedicine**，或直接运行
`SuperMedicineGUI.exe`。桌面程序会启动受管的本机 Web 服务并打开应用窗口；
关闭窗口时，受管服务也会退出。

源码环境可先运行 `supermedicine web`，再通过浏览器验证同一套界面和 API。

## 远程访问

监听非回环地址时必须提供令牌文件。文件内容应为一行随机长令牌：

```powershell
supermedicine web --host 0.0.0.0 --port 8000 --auth-token-file C:\secure\supermedicine-web.token
```

浏览器顶部的“访问令牌”输入框只把令牌保存在当前标签页的
`sessionStorage` 中；关闭标签页后会清除。不要把令牌提交到仓库、写入 URL
或发到日志中。远程部署还应在 SuperMedicine 前配置 HTTPS 反向代理和网络
访问控制。

## 首次使用

1. 打开“工作区”，创建或选择一个研究工作区。
2. 打开“设置”，在其中的 LLM 区域添加提供方并切换为当前模型；API 密钥建议使用环境变量。
3. 返回“对话”选择工作区并发送问题。
4. 按需导入论文、记录经验、配置工具和实验。
5. 如果操作失败，先打开“诊断”检查配置、模型和安装状态。

“设置”集中展示日志、LLM、Agent、权限、RAG 与实验引导配置。应用日志默认保留总量
上限为 1 GiB；每次连续启动只写入一个以本地时间命名的
`supermedicine-YYYYMMDD-HHMMSS.log`，CLI 等单次命令会在文件名中加入命令后缀。
每条日志都带严重级别和来源端标记。

WebSocket 断线会自动重连。界面显示“已断开”时，可先确认后台命令仍在运行，
然后重新点击“连接”；若模型不可用，界面只显示可执行的检查建议，详细原因
保留在本机受保护日志中。

## 数据与安全边界

- 默认配置和运行数据位于项目的 `.supermedicine` 目录；设置 `SM_CONFIG`
  后，配置、数据库、实验会话和待确认自进化建议使用该配置文件的同级目录。
- 论文、经验、实验和工具操作受权限策略约束。
- 导入本地文件或授权外部目录前，请确认路径属于预期研究资料。
- “完全访问”以及自进化写入等高风险操作仍需要显式确认。

## 服务验证

服务启动后可检查健康端点：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/health
```

预期返回 `status: ok`。若端口被占用，改用 `--port`；若安装环境缺少依赖，
运行 `supermedicine diagnose` 并按输出修复。
